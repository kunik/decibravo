# DeciBravo

Застосунок для Android, який міряє оплески учасників змагання мікрофоном телефона й складає таблицю результатів. Працює без мережі: єдиний дозвіл — мікрофон. Інтерфейс українською, лише портретна орієнтація, лише темна тема.

## Як зібрати

Потрібен JDK 17 й Android SDK. З кореня проєкту:

```
./gradlew :app:assembleDebug
```

APK буде в `app/build/outputs/apk/debug/app-debug.apk`. Тести: `./gradlew :app:testDebugUnitTest`.

## Як встановити на телефон

- Скопіюйте `app-debug.apk` на телефон, відкрийте його й дозвольте встановлення з невідомих джерел, або
- підключіть телефон кабелем (з увімкненим налагодженням по USB) і виконайте `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

Збірка підписана налагоджувальним ключем цього Mac. Оновлення треба збирати на ньому ж: інакше телефон відмовиться оновлювати застосунок, і доведеться вилучити його разом із даними.

## Де лежать дані

Усе зберігається в `Android/data/app.decibravo/files/` на телефоні:

- `calibration.json` — калібрування телефона;
- `competitions/<id>/competition.json` — змагання й учасники;
- `competitions/<id>/measurements/` — зараховані заміри: ряд кадрів (`.json`) і запис звуку (`.wav`).

Щоб забрати дані, підключіть телефон кабелем і скопіюйте цю теку (на Mac — через Android File Transfer) або виконайте `adb pull /sdcard/Android/data/app.decibravo/files/`. Вилучення застосунку стирає й ці дані.

## Коротка інструкція судді

1. Поставте телефон на штатив в одній точці, не поруч з окремими людьми.
2. Прикрийте мікрофон від вітру.
3. Фон міряйте на місці, у тиші: кнопка «Виміряти» в налаштуваннях змагання.
4. Натискайте «Старт», коли учасник замовк. Замір зупиниться сам: після найдовшого заміру або після паузи.
5. Результат перегляньте й натисніть «Зарахувати» або «Переміряти».
6. Таблицю можна скопіювати кнопкою «Скопіювати таблицю».
7. Перед змаганням підберіть калібрування на пробних замірах: екран «Калібрування» зі списку змагань.

> **Увага:** вилучення застосунку з телефона стирає всі змагання, результати й записи. Перед вилученням або перевстановленням з іншого комп'ютера заберіть теку `Android/data/app.decibravo/files/` кабелем.
